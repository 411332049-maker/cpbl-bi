得分與失分

每個點是「某隊某年」，泡泡越大勝率越高

點一下任一個點，查看球隊、年份與戰績。

斜線為「得分 = 失分」：線的右下方代表得分多於失分。

得分、失分由官網各隊球員打擊／投手成績加總而得。各隊另以不同點形狀區分。

畢氏期望勝率 vs 實際勝率

實際勝率 − 畢氏勝率，由高到低排序

畢氏勝率 = 得分² ÷（得分² + 失分²），用得失分估計「應有」的勝率。

正值：實際贏得比得失分預期多，可能是運氣好或關鍵時刻表現好；負值則相反。

打擊與投手指標

長條為區間最後一年；灰點為該隊在區間內的平均。打擊率、防禦率由球員成績加總後計算。
